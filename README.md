# TradeLog 交易日记

一本只属于你的交易日记：记录每笔交易、截图和复盘，自动统计胜率、盈亏和 R 值。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 应用本体。双击就能在浏览器里使用 |
| `manifest.webmanifest` | 手机"添加到主屏幕"用的应用信息 |
| `sw.js` | 离线缓存，只在网站上生效 |
| `_headers` | Netlify 的缓存与安全设置 |
| `icons/` | 应用图标（192、512 和苹果主屏幕图标） |

## 本地使用

双击 `index.html` 即可。数据保存在当前浏览器里：

- 换一个浏览器打开会看不到之前的记录
- 清除浏览器数据会丢失记录
- 请定期在「备份管理」里导出 JSON 备份

## 发布成网站

- **GitHub Pages**：把这些文件上传到仓库根目录，在仓库的 Settings → Pages 选择 `main` 分支，就会得到一个网址。
- **Netlify**：打开 https://app.netlify.com/drop ，把整个文件夹拖进去，就会得到一个网址。

网站版和本地文件的数据是分开存的：先在本地导出 JSON 备份，再到网站里导入。
